  蓝色大肥鱼 DeepSeek Harness 懒人客户端 · 使用说明
═══════════════════════════════════════════════════════════

【这是什么？】
  基于 GitHub 开源项目 deepseek-ai/deepseek-harness
  （https://github.com/deepseek-ai/deepseek-harness）做的一键部署客户端。
  ★ 界面是独立的桌面应用窗口（Electron 客户端，不是浏览器）：
    无边框、无地址栏、无标签页，高清显示（支持高 DPI 缩放），
    和普通软件一样使用。
  网页内容与官方 DeepSeek Harness 完全一致。

【安装（只需一次）】
  1. 双击「蓝色大肥鱼DSH-安装程序.exe」
  2. 安装界面会自动检测你的电脑是否装了 Node.js：
     · 已装 → 显示"✔ 已检测到 Node.js vXX"
     · 没装 → 显示"✘ 未检测到 Node.js"，
       并出现"☑ 安装 Node.js（自动下载约 35MB）"复选框（默认已打勾）
  3. 界面下方有两个可勾选项（默认已勾选，可取消）：
     ☑ 添加桌面快捷方式　　☑ 安装完成后直接打开
  4. 点「安装」，等待自动完成（解压 + 下载依赖，约 2~5 分钟）
  5. 首次使用按提示输入 DeepSeek API Key
  6. 独立窗口打开，开始使用！

【日常使用】
  双击桌面上的「DeepSeek Harness」快捷方式（或安装目录里的
  蓝色大肥鱼DSH.exe）
  · 服务自动在后台启动（无黑窗口），日志保存在 data\server.log
  · 关闭窗口时会询问"是否同时停止服务"，点「是」即全部退出
  · 标题栏右侧是最小化/最大化/关闭按钮（系统原生样式）
  · 标题栏空白处可拖动窗口，双击可最大化/还原

【两种模式】
  · 蓝色大肥鱼DSH.exe  桌面客户端（默认，推荐）
  · launcher.exe        浏览器模式（备用：双击后自动打开浏览器）

【常用操作】
  · 换 API Key / 查余额：打开客户端后，点标题栏右侧的 🔑 按钮，
    在面板里直接修改 Key 或查询 DeepSeek 余额（无需关闭客户端）
  · 升级到最新版：双击安装目录里的「更新.bat」
  · 查看源码（进阶）：双击安装目录里的「下载GitHub源码.bat」
  · 卸载：设置 → 应用 → 找到「蓝色大肥鱼 DeepSeek Harness 懒人客户端」
    → 卸载（自动停服务、删快捷方式、删目录）

【文件都在哪？】
  · 默认安装位置：C:\Users\你的用户名\DeepSeek Harness
  · 你的工作目录（AI 写的文件都在这）：
    C:\Users\你的用户名\DeepSeek-Harness-Workspace
  · API Key 存放位置：C:\Users\你的用户名\.dsh\.credentials.yaml
  · 历史会话记录：C:\Users\你的用户名\.dsh\sessions

【常见问题】
  Q: 杀毒软件（Windows Defender）提示"已保护你的电脑"？
  A: 程序已带代码签名。若个别杀软仍误报：
     点「更多信息」→「仍要运行」；
     或在 Windows 安全中心 → 病毒和威胁防护 → 排除项里
     添加安装目录。程序完全本地运行，不上传任何数据。

  Q: 服务窗口关掉后网页打不开了？
  A: 桌面客户端没有独立服务窗口：关闭客户端窗口 = 停止服务。
     重新双击「DeepSeek Harness」快捷方式即可。

  Q: 提示端口被占用？
  A: 会自动换一个可用端口。如果已经有另一个 DSH 在运行，
     客户端会直接使用它（关闭客户端不会影响那个服务）。

  Q: 下载很慢？
  A: 默认使用国内镜像（npmmirror），失败会自动切换官方源。

  Q: 网页显示错误 / 没有反应？
  A: 查看安装目录 data\server.log 的最近日志，截图发给蓝色大肥鱼即可。

  Q: 安装包怎么变大了？
  A: 新版桌面端内置了 Electron 运行环境（Chromium 内核），
     所以安装包约 80MB。换来的是稳定高清的独立窗口，
     且不再被杀毒软件误报（此前 WebView2 方案会误报）。

【安全提示】
  · API Key 只保存在你自己电脑的 .dsh\.credentials.yaml 里，不会上传
  · 服务只监听 127.0.0.1（仅本机可访问），不会暴露到局域网
  · 安装程序免管理员权限，不写注册表系统区（仅 HKCU 卸载项）

  祝使用愉快！有问题随时找蓝色大肥鱼 🐟
